# TU Chicken Zone Management System — Flutter starter

This is a starter Android app based on the supplied reference images. It includes a red/white dashboard, bottom navigation, purchase/sale/expense/Udhaar entries, simple totals and local SharedPreferences storage.

## Build APK
1. Upload this project to a GitHub repository (branch `main`).
2. Open **Actions** and run **Build Chicken Zone APK** (or push to main).
3. Download the `Chicken-Zone-APK` artifact from the workflow run.

## Important
This is an initial working starter, not the complete production accounting application. Customer identity fields, inventory/kg formulas, PDF export, backup/restore, demo expiry and validated license activation still need implementation and testing. Entries are currently stored locally on the device.
